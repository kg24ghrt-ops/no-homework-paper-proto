# No Homework — Notebook Paper Prototype

Generates a JIS B5 lined notebook page (182×257 mm) at 300 DPI using Pillow and displays via Kivy.

## Dimensions
JIS B5: 182 mm × 257 mm, ~2150×3035 px at 300 DPI.

Printing actual physical size depends on printer scaling.

## Run
python main.py

## Tests
pytest

## CI
GitHub Actions: test + android build.
